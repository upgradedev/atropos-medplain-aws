    THE REASONING CAN BE FLEXIBLE. THE GATE IS FIXED.
    Three agents. One publication boundary.
    BUILT WITH STRANDS SDK
    01 / PARSE
    Find the clinical facts.
    The parser reads the discharge packet and FHIR bundle, then evaluates lab values against the supplied reference ranges.
    LabAndDischargeParserAgent
    02 / VERIFY
    Check what must stay exact.
    The verifier checks medication dosage and frequency, and looks for interactions in a small, curated demonstration rule set.
    DrugAndContraindicationVerifierAgent
    03 / EXPLAIN
    Make the packet readable.
    The patient advocate creates the explanation. The deterministic gate checks the result and sends discrepancies back for correction.
    PatientAdvocateExplainerAgent
    
    
    i
    An engineering demonstration, not clinical care.
    These packets are synthetic. The gate checks fidelity to the supplied record; it does not establish that the original prescription is appropriate. Interaction checks cover selected demonstration pairs and are not exhaustive. For questions about your own care, ask your clinician or pharmacist.
